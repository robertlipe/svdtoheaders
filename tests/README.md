# Test Suite Documentation

This directory contains the test suite for the `svdtoheaders` project.

## Running Tests

To execute the tests, navigate to the project root directory and run the following command:

```bash
venv/bin/pytest -v
```

This command will run all tests located in this directory and its subdirectories.

## Test Structure

Tests are organized as follows:
- `test_svdtoheaders.py`: Contains unit tests for the main `svdtoheaders` script.
- SVD files (`.svd` extension): These are used as input for various tests.
